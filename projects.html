AI in Kindergarten — A Practical Guide

// 2026 · Guide · Written in Norwegian

Working in the kindergarten sector, I have experienced a clear need for guidance on how artificial intelligence should be used in early childhood education. AI tools are already part of everyday work, but there have been few concrete guidelines on what is safe, lawful and appropriate when children's information is involved.

On my own initiative, I wrote a 24-page guide for kindergarten staff on safe, responsible and purposeful use of AI. It covers privacy and confidentiality, information security and AI-enabled scams, recommendations for use, practical examples and a checklist, with references to Norwegian law and guidance from Datatilsynet, Udir and NSM. The guide ends with a declaration of how AI was used in making it.

Personal Portfolio Website

// 2025 — 2026 · Web Development

A personal portfolio website built from scratch using HTML, CSS, and JavaScript. Features a dark cyberpunk aesthetic with an animated network background, falling glyphs, and moving data packets. Includes pages for biography, CV, projects and news, plus a TryHackMe progress section that is generated from synced profile data. Built using AI as a development partner. I direct the design, content and security decisions, and review and test all code.

Deployed via GitHub Pages with a custom domain configured through DNS management — including A-record and CNAME setup and SSL/TLS certificate provisioning for HTTPS enforcement. Hardened behind Cloudflare with Full (Strict) TLS, HSTS, security headers and a Content Security Policy.
